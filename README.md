# MusicBay

Мобильное приложение на Flutter для [сервера MusicBay](https://git.siakiera.solutions/music-player/backend). Вся музыка
живёт на вашем сервере: вы загружаете файлы, сервер их обрабатывает, а приложение играет их с любого устройства.

Приложение не работает без сервера. Как его поднять, написано в его README.

## Возможности

**Аккаунт**
- Вход и регистрация на сервере, адрес которого указывается на экране входа.
- Токены обновляются сами. Если сессия закончилась на сервере, приложение просит войти снова.
- Экран аккаунта: занятое место и лимит загрузок, устройства с выходом на любом из них, качество звука.

**Музыка**
- Загрузка файлов частями: обрыв связи стоит одного куска, а не всего файла. Файл, который на сервере уже есть, не
  занимает квоту и готов сразу.
- У каждого трека три уровня видимости: только для себя, по ссылке и для всех с поиском.
- Свои треки можно переименовать, сменить им видимость и удалить с сервера.
- Поиск по публичным трекам сервера с догрузкой при прокрутке.
- Медиатека, лайки, альбомы и плейлисты: создание, переименование, удаление, добавление и удаление треков.

**Воспроизведение**
- Плеер на `just_audio`: перемотка, shuffle, repeat, мини-плеер, управление с экрана блокировки.
- Три качества: AAC 96 кбит/с, AAC 192 кбит/с и FLAC без потерь. Если нужного у трека нет, играет ближайшее.
- Офлайн: сохранённые треки кэшируются при прослушивании, из плейлиста можно скачать сразу до 100 треков.

**Главная** собирается на устройстве: микс дня и альбомы из вашей медиатеки плюс публичные треки ваших артистов. На
пустом сервере она пустая, пока не загружена музыка.

## Быстрый старт

Нужны Flutter 3 и запущенный сервер.

```bash
flutter pub get
```

```bash
flutter run
```

На экране входа укажите адрес сервера и создайте аккаунт. Адрес можно подставить заранее:

```bash
flutter run --dart-define=SERVER_URL=https://music.example.com
```

С эмулятора Android компьютер виден как `http://10.0.2.2:8080`.

## Как приложение работает с сервером

Описание API лежит в репозитории сервера, в `api/openapi.yaml`.

| Что | Как |
|---|---|
| Токены | живут в защищённом хранилище; на ответ 401 приложение один раз обновляет токен и повторяет запрос |
| Версия | каждый запрос несёт `X-Client: android/1.0.0`; на ответ 426 приложение показывает экран обновления |
| Загрузка | `POST /uploads`, затем куски `PATCH /uploads/{id}`, затем `POST /uploads/{id}/complete` |
| Новый трек | играть можно, когда `status` станет `ready`; до этого приложение спрашивает сервер каждые 3 секунды |
| Поток | ссылка подписана и живёт 6 часов; перед воспроизведением приложение обновляет истёкшие ссылки |
| Обложки | кэшируются по пути, а не по подписанной ссылке, поэтому не скачиваются заново |
| Медиатека | полностью перечитывается не чаще раза в 30 минут и хранится на устройстве для поиска и офлайна |

Пока не используются:

- **P2P через I2P.** Музыка идёт только по HTTP(S): для I2P на устройстве нужен роутер.
- **`/sync`.** В его ответах нет ссылок на потоки, а приложению они нужны для работы со списками.

## Тесты

```bash
flutter test
```

Тест `test/server_test.dart` проходит весь путь пользователя через настоящий сервер, поэтому без адреса он пропускается.
На сервере он оставляет тестовый аккаунт:

```bash
flutter test test/server_test.dart --dart-define=TEST_SERVER=http://localhost:8080 --dart-define=TEST_AUDIO=путь/к/файлу.mp3
```

## Сборка APK

```bash
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`. Файлы поменьше, отдельно для каждой архитектуры:

```bash
flutter build apk --release --split-per-abi
```

После смены версии в `pubspec.yaml` поменяйте и `kAppVersion` в `lib/constants.dart`: эту версию сервер сверяет со своим
минимумом.

## Структура

| Где | Что там |
|---|---|
| `lib/services/api_service.dart` | запросы к серверу, токены, загрузка файлов, ошибки на русском |
| `lib/providers/music_provider.dart` | состояние экранов: вход, медиатека, поиск, плейлисты, лайки, главная |
| `lib/providers/audio_provider.dart`, `lib/services/audio_player_service.dart` | воспроизведение |
| `lib/services/cache_service.dart`, `lib/services/library_index_service.dart` | офлайн-кэш и индекс медиатеки |
| `lib/models` | трек и плейлист в том виде, в каком их отдаёт сервер |
| `lib/screens`, `lib/widgets` | интерфейс |
